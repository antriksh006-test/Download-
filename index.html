About FakeInfo

FakeInfo creates fictional identities using the Random User API. These profiles are useful for interface mockups, software testing, fictional characters, demonstrations and harmless jokes.

Important: Generated profiles are fictional and intended for entertainment, testing and mockup purposes. Do not treat generated information as belonging to a real person.

Client-side only

FakeInfo does not require an account, database or backend. Generation and profile handling happen directly in your browser.
